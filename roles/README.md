# Role cards

The nine `*.md` files here are the original harness role cards, copied unchanged
from the Buzz handover (2026-11-07). They are the source of truth; each teammate
is pointed at its card on every wake-up.

`en/` holds the English translations from the same handover, for reading only.
They don't replace the originals.

`scranton-help.md` is new for Scranton (the helper that files feedback as issues).

Growth, Customer Support, Hardware Advisor, Web Developer (Cursor) and Video Editor
have no saved cards yet (to confirm). Add a card here and set `role_card` in
`config.toml` when you have one.
